# Swipe Rush — Contribution

Swipe Rush is a fast-paced Godot 4.3 arcade game where players move between rooftop lanes, avoid obstacles, and deliver packages.

This repository contains my contributed and modified version of the project. I did not create the original game.

## My contribution

- Added configurable package destinations mapped to the three lanes.
- Added destination indicators on packages and in the HUD.
- Added one-active-delivery handling with correct and incorrect destination outcomes.
- Added configurable delivery bonuses and consecutive delivery combo tracking.
- Preserved the existing rarity, scoring, safe-lane spawning, and difficulty systems.

## Run locally

1. Install Godot 4.3 or a compatible Godot 4 release.
2. Open `project.godot` in Godot.
3. Run the main scene/project.

The project includes keyboard and mouse controls for desktop testing, as well as mobile touch controls.
